# Seguridad

Este proyecto aún no tiene autenticación ni aislamiento entre usuarios. **No lo
expongas a internet ni hagas público el repositorio** hasta completar las fases
de seguridad y revisar el historial.

Para informar una vulnerabilidad, usa la opción de reporte privado de
GitHub Security Advisories del repositorio, si está habilitada. No publiques
secretos, datos financieros ni PDFs en un issue. Si no está disponible el
reporte privado, contacta directamente al mantenedor por un canal privado.

La configuración sensible y su rotación se describen en
[`docs/seguridad-secretos.md`](docs/seguridad-secretos.md).
