# docs/

Las rutas de la tabla son relativas a `docs/`.
Documentación que el agente lee bajo demanda, no el código.

| Archivo | Para qué |
|---|---|
| `INDEX.md` | Mapa de archivos: dónde vive cada cosa |
| `STATUS.md` | Estado actual del proyecto, máximo 15 líneas |
| `plan-fase-3.md` | Diseño de la categorización y sus decisiones |
| `plan-fase-4.md` | Diseño de la web app y sus decisiones |
| `adr/` | Decisiones difíciles de revertir, con contexto y consecuencias |
| `agents/` | Configuración de las skills de ingeniería |

Regla: si un documento deja de ser cierto, se borra su línea. No se comenta lo viejo.
